# Recreate the paper figures

These scripts use the precomputed results in [figure_data/](../figure_data/README.md).
You do not need a GPU, `input.pkl.gz`, embeddings or trained models.
Run commands from the repository root:

```bash
pip install -r figures/requirements.txt
python figures/plot_figure3.py
python figures/plot_figure4.py
python figures/plot_figure5.py
```

| Paper figure | Script | Output filename |
| --- | --- | --- |
| 3: Protein model comparison | `plot_figure3.py` | `FigMain` |
| 4: Robustness | `plot_figure4.py` | `FigRob` |
| 5: Comparison with recent models | `plot_figure5.py` | `FigModel` |
| 6: External validation | `plot_figure6.py` | `FigPTR` |

PDF, PNG and SVG files are written to `outputs/figures/`. Figures 3 and 5 also
produce their Spearman counterparts. Figure 4 produces only the main Pearson
figure by default; use `--metric both` to also generate the Spearman version. Figures 1–2 are explanatory diagrams and
are not generated by these scripts. Original figure filenames are preserved.
Use `--formats png` or `--formats pdf` to select an output type; `--help` lists
all options. Arial is used in the manuscript; providing it gives matching fonts.

## Figure 6

Download **Table EV3** from [Eraslan et al. (2019)](https://doi.org/10.15252/msb.20188513).
Place `44320_2019_BFMSB188513_MOESM5_ESM.zip` in `data/raw/eraslan2019/`, then run:

```bash
python figures/plot_figure6.py --table-ev3 data/raw/eraslan2019/44320_2019_BFMSB188513_MOESM5_ESM.zip
```

An extracted `Table_EV3.tsv` or an absolute path also works. The script combines
the downloaded measurements with the paper's precomputed prediction values,
recalculates correlations and confidence intervals, and draws the figure.
The 5,000 resampling repetitions can take several minutes on a CPU. Table EV3
is ignored by Git. See [calculation details](figure6_details.md) if needed.

## Statistical calculations

- Figure 3: means and sample SD across ten matched runs; two-sided paired
  t-tests with Holm correction across eight comparisons (two model pairs ×
  four tissues), separately for Pearson and Spearman. Exported tables include
  both raw and adjusted p-values in `outputs/figure3/`.
- Figure 4(a): mean and sample SD of run-wise tissue-average correlations.
  (b): `100 × (control − mRNA-only) / (native T5u − mRNA-only)` at c50.
  The length control uses `log1p(length)` scaled using the training subset's
  mean and sample SD. (c): mean and sample SD of paired gains in each class. (d): mean and sample SD
  of paired gains across ten runs for five held-out Pfam motifs (SH3, protein
  kinase, RRM, C2H2 zinc finger and WD40). Each gain is mRNA+T5u minus
  mRNA-only on the same run. All four panels use precomputed results; no
  Pfam annotation or model training is required.
- Figure 5: each point is a run's mean across 78 tissue correlations; diamonds
  and error bars show mean and sample SD across ten runs. No significance tests.
- Figure 6: correlations and paired differences with 95% confidence intervals
  from 5,000 protein-cluster resampling repetitions.

Sample SD uses `ddof=1`. These procedures match the manuscript. Regenerating
figures from saved results does not regenerate the original model predictions.
